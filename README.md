# TuxBuilder 🐧🔧

**Graphical application installer for Debian/Ubuntu systems**

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Python 3.6+](https://img.shields.io/badge/python-3.6+-blue.svg)](https://www.python.org/)
[![Platform: Linux](https://img.shields.io/badge/platform-Linux-lightgrey.svg)](https://debian.org)

A simple and efficient installer for multiple applications via APT with graphical interface.

## ✨ Features

- ✅ Batch installation of multiple applications
- ✅ Support for Debian/Ubuntu and derivatives

## 📦 Requirements

- Debian/Ubuntu-based operating system
- Python 3.6 or higher
- Tkinter (usually pre-installed)
- Administrator privileges for installation

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/danueldev/tuxbuilder.git
cd tuxbuilder

# Run the application
python3 main.py
